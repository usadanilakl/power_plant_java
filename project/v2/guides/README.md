# Guides

How subsystems work, and how to operate them. Advisory content lives here — anything
that cannot be machine-checked is a guide, not a convention
([[0003-conventions-require-enforcement]]).

Guides embed real code by line range rather than pasting snippets, so they cannot
drift silently. Every referenced file goes in the `code_refs` frontmatter list, which
CI validates.

Empty until there is a subsystem to describe.
