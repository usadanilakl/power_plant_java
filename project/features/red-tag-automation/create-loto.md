1. Select LOTO Procedures tab in the top bar:
    - when LOTO tab is clicked loto list opens, but it can be either grouped (usually by status)
    - to group it - drag "Status" column header to yellow section with text ("Drag a column header here to group by that colunm)
    - to ungroup it - drag "Status" from yellow section to table header - the status header will be placed in between columns where it was dropped. 
2. Click NEW ISOLATION button in the left menu
3. Select LOTO in side-dropdown (only option)
4. Select Issue LOTO with NO Standard Procedure
5. in the loto building page fields type:
    - Job Description
    - Equipment Description
    - LOTO type - type text "LOTO"
    - Add loto points - for each point: 
        - Click Add a Device Manually button
        - Isolation Device Descrciption - loto point description
        - Isloation Device Large Description - zero-energy text
        - Isolation Device PNID - loto point tag nubmer
        - Isolation Device Locaion - loto point specific location
        - Isolated Postion - loto point isoPos.name
        - Normal Postion - loto point normPos.name
        - Click ok
    - Click Continue
