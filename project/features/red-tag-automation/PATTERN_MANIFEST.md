# Red Tag Automation — Pattern Manifest

SikuliX matches small reference images against the live screen. Every image the
LOTO automation needs is listed here, generated by [generate-patterns.py](generate-patterns.py)
from the full-window screenshots in [screenshots/](screenshots/).

- **Logical names** live in `RedTagPattern` (the enum is the source of truth).
- **Image files** are bundled at `src/main/resources/automation/redtag/patterns/`.
- On startup `PatternCatalog` extracts them to `${user.dir}/automation/redtag/patterns/`
  (override with `redtag.automation.pattern-base-path`).

## How patterns are used

A pattern is a **distinctive anchor** — a label, button, title or status text.
The automation finds the anchor, then clicks at a pixel **offset** to reach the
field beside it. Offsets live as `*_DX` / `*_DY` constants in `LoginFlow` and
`LotoBuildFlow`. Blank input fields are never used as patterns (not unique).

## Regenerating

```
cd project/features/red-tag-automation
python generate-patterns.py
```

Re-run after recapturing any screenshot. If a pattern matches poorly on the live
machine, adjust its crop box in `generate-patterns.py` and re-run — a contact
sheet is written to `.crop_tmp/contact-sheet.png` for visual review.

## ⚠️ Resolution dependency

These crops are pixel-real slices of screenshots taken at the operator's desktop
resolution. They match the live screen **only at that same resolution / DPI**.
On a different display, recapture the screenshots and re-run the script. The
`redtag.automation.default-similarity` (0.80) absorbs minor anti-aliasing
differences; lower it slightly if matches are flaky.

## Not yet captured (out of LOTO scope)

The post-**Continue** "Information" form (lock box, requestor, work scope,
requested-by) and the final save / permit-number read-back are **not scripted** —
no screenshots of those screens exist yet. `LotoBuildFlow.clickContinue()` stops
at Continue. To finish full end-to-end automation:

1. Screenshot the Information form and the saved-LOTO list row.
2. Add the new patterns to `RedTagPattern` + `generate-patterns.py`.
3. Extend `LotoBuildFlow` with `fillInformationForm()` + `readPermitNumber()`.
