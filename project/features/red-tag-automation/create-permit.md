1. Select permit type tab in the top bar (Safe Work, Hot Work, Reclassified Confined Space, Permit Required Confined Space):
    - when permit tab is clicked list opens, but it can be either grouped (usually by status)
    - to group it - drag "Status" column header to yellow section with text ("Drag a column header here to group by that colunm)
    - to ungroup it - drag "Status" from yellow section to table header - the status header will be placed in between columns where it was dropped. 
2. Click NEW PERMIT button in the left menu
3. Select Issue Permit with NO Template button in the right upper corner
4. Form opens zoomed in, to see all fields it can be zoomed out: click magnifying glass with - in it 3 times. 
5. Fill out all applicable fields and checkboxes
6. Click floppy disk to save, sometimes an error apears (ERROR_RECORD_IN_USE), it can be acnowledged by hitting enter or clicking OK and trying again. 
7. After permit is saved it will appear at the top of the list (if list is ungrouped)
8. Save the red tag permit number and associated it with respective permit/package in the app
9. ONLY for Safe Work: After all permits are created:
    - Click on the permit we just created
    - Click "Modify" button in the left menu
    - Click "Associate" button in the top bar
    - Maximize associate dialog
    - Select Issued LOTOs tab at the bottom:
        - search by job description:
            - click clear button
            - type description
            - click search
            - double click proper item
            - double ckicked item should appear in the right section of the dialog
    - Select Issued Permits tab at the bottom:
        - search all associated permits
        - add one by one to the right section of the dialog
    - Automation can stop at this point for double checking the information.
