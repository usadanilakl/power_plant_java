1. Affected Employee - qualified, allowed to work under LOTO
2. Authorized Employee - Hanger/Verifier
3. Qualified Employee - performs electrical equipment LOTO
4. LOTO Procedure
	- Development of a new LOTO:
		- prerequisites for applying LOTO (system shutdown, electrical switching, grounding)
		- methods to control hazards
		- sequencing (installation and removal)
		- identify zero-energy check
		- new LOTO is verified by second qualified person
		- perform walkdown
		- mark as ready for testing - the first time it is hung
		- if testing is successful - mark as "Approved" - approval is performed by manager
		- if procedure is modified it is marked as NEW and needs to be run through all steps of a new LOTO
	- Install LOTO
		- Isolate equipment
		- Check zero-energy
		- Lock
		- Verify
	- Walkdown - Requestor and workers walk LOTO down to verify zero energy and proper LOTO installation
	- Activation - Control authority issues LOTO
