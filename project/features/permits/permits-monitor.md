## View modes
Two views over the same open work: **List** (the tables above) and **Map** (the plant layout, with
a toggleable layer per record type). See
[permits-monitor-map-view.md](permits-monitor-map-view.md) for the placement rules that decide
where a permit is drawn, and for the theme fix that gave the page a background.
