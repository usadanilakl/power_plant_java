Install Application

Installing puts the app on your home screen and lets it open full-screen.

On iPhone or iPad

  1. Tap the Share button in Safari.
  2. Choose Add to Home Screen.
  3. Tap Add.

Safari can't install an app for you — this is the only way, and it works.

Your browser isn't offering an install here.

Either it's already installed, or this browser doesn't support it. In Chrome, look for Install or Add to Home screen in the browser menu.
