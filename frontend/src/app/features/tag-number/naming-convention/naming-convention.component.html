Naming Convention:

Tag Number Format: [Unit]-[Equipment Type]-[System]-[Sequential Number]

  • Unit: 01, 02, 03
  • Equipment Type:
    • V - Manual valve
    • MOV - Motor Operated Valve
    • AOV - Air Operated Valve
    • PCV - Pressure Control Valve
    • TCV - Temperature Control Valve
    • FCV - Flow Control Valve
    • PMP - Pump
    • CMP - Compressor
    • XRF - Transformer
    • PIT - Pressure Transmitter
    • TIT - Temperature Transmitter
    • FIT - Flow Transmitter
    • If equipment is not in the list, come up with 3 letter name for it
  • System:
    • SWS - Service Water System
    • DWS - Demin Water System
    • DWT - Demin Water Treatment System
    • CND - Condensate System
    • BFW - Feed Water System
    • LPS - LP Steam System
    • IPS - IP Steam System
    • HPS - HP Steam System
    • CTP - CT System
    • STP - ST System
    • FGS - Fuel Gas System
    • CCW - Closde Cooling Water System
    • If system is not in the list, come up with 3 letter name for it
